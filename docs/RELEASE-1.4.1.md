# PlainOB 1.4.1 — Preview

Simple Notes & Tasks. A small Obsidian dashboard focused on finding notes, browsing four knowledge directories and managing everyday tasks.

## Included

- Keyword search across titles and body text, with highlighted sentence previews and navigation.
- Projects, Areas, Resources and Archive, with folder browsing and optional bookshelf covers.
- Backlog / Active / Done for standalone tasks and independently scheduled project steps.
- Chinese/English interfaces and a four-step installer with numbered or existing-folder mappings.
- Optional note templates, property-dropdown integration and AI rules.

## Install or upgrade

Windows and macOS desktop; Obsidian 1.15.0+. Download the installer ZIP, or the individual `main.js`, `manifest.json` and `styles.css` assets. Place the three files in your vault's configuration directory under `plugins/plainob/` and enable PlainOB. The installer ZIP includes instructions.

When upgrading, preserve your `data.json`, backups, notes, templates and lists. Do not rerun new-system setup. Existing user files are not overwritten by a code update.

## Preview status

72 automated checks pass. A user has reported successful installation and task use on Windows and macOS. Extended acceptance details and current limitations are in `docs/RELEASE-CHECKLIST.md`. Mobile, bulk legacy-note migration and automatic folder-rename migration are not included. Sync and AI services are optional, separately configured tools.
